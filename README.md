# Scaffographe

Site web du collectif Scaffographe — [scaffographe.com](https://scaffographe.com).

Vite + React + TypeScript + Tailwind CSS + shadcn/ui. Static output, no backend.

## Develop

```sh
npm install
npm run dev      # http://localhost:8080
```

## Build

```sh
npm run build    # outputs to dist/
npm run preview  # serve dist/ locally
```

## Routes

- `/` — French
- `/en` — English
